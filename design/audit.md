## 两个产品方向

### 方向 A：Conversation-first 通信工作台（推荐）

- 主导航优先展示最近会话、Room 和未读/失败状态。
- Agent 与联系人是“参与者目录”，用于创建或管理会话，不再作为历史的三层父节点。
- Header 清楚显示会话类型、参与者、路由模式和连接路径。
- 优点：符合即时通信心智，跨设备扩展自然，最近任务更容易回到。
- 缺点：需要重构侧栏和会话筛选。
- 风险：重度按 Agent 管理历史的用户需要过滤器作为补偿。

### 方向 B：Agent-first 驾驶舱

- 保留 owner → Agent → conversation 树，强化状态、计数和折叠。
- 群聊/Room 作为独立第二棵树。
- 优点：改动小，便于查看每个 CLI 的历史。
- 缺点：跨用户 Room 和联系人始终像附加功能；窄侧栏认知层级过深。
- 风险：产品继续被理解为 CLI Manager，而不是 Agent 通信层。

## 视觉方向

推荐“Quiet Signal / 安静信号”：中性石墨和暖白表面、低饱和青绿色作为活跃协作信号、琥珀表示等待确认、红色只用于失败/危险。使用系统字体和 4px 网格，避免渐变、玻璃拟态、超大圆角和营销式空状态。
